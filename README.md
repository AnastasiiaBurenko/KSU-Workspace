KSU Workspace

Персональний цифровий простір студента та викладача ХДУ за принципом Notion, інтегрований з університетською екосистемою.

Ідея проєкту:
Система об'єднує дані з KSU-online (розклад, дисципліни, завдання) з можливістю самостійно організувати їх у сторінки, задачі та бази даних.

Передбачувані сутності даних:
Користувачі: Студенти, Викладачі, Адміністратори.
Університетські об'єкти: Факультети, Спеціальності, Групи, Дисципліни, Викладачі, Розклад, Завдання.
Особисті об'єкти: Персональні сторінки, Блоки, Бази даних, Задачі, Файли.

Посилання на розгорнуту сторінку: [GitHub Pages](https://github.com/AnastasiiaBurenko/KSU-Workspace.git)
