Звіт з лабораторної роботи №1

Посилання на репозиторій GitHub: https://github.com/AnastasiiaBurenko/KSU-Workspace  
Посилання на опубліковану сторінку (GitHub Pages):
https://anastasiiaburenko.github.io/KSU-Workspace/

Для розробки проєкту було створено локальну папку KSU-Workspace, ініційовано репозиторій Git та виконано п'ять логічних комітів згідно з вимогами завдання:

    Коміт 1 (.gitignore): Створено файл конфігурації для виключення системних файлів, папки залежностей Node.js (node_modules) та службових каталогів Python (__pycache__, .venv).

    Коміт 2 (README.md): Створено паспорт проєкту з детальним описом концепції KSU Workspace (інтеграція з KSU-online, ролі користувачів, архітектура та план розвитку).

    Коміт 3 (index.html): Розроблено стартову сторінку із семантично коректним HTML-скелетом (<!DOCTYPE html>, атрибут мови lang="uk", кодування utf-8, адаптивний viewport, заголовки та опис функціоналу).

    Коміт 4 (app.py): Написано простий локальний сервер на мові Python для тестування та перегляду вебсторінки на локальному порту 8000.

    Коміт 5 (docs/REPORT.md): Додано файл звіту з повним описом виконаних етапів роботи.
